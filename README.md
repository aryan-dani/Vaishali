# Hotel Vaishali — Concept Redesign (Next.js + React)

An editorial, heritage-driven web redesign for **Hotel Vaishali** (*1218/1, Shivajinagar, Fergusson College Road, Pune 411004*), built with **Next.js (App Router)**, **React**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

## Highlights
- **Floating Glassmorphism Navigation Dock**: Smooth spring-animated active section pill (`layoutId`) for desktop and mobile.
- **Tactile Broadsheet Menu Ledger**: Interactive 7-category menu (*Breakfast, Dosas, Uttapam, Rice, Thalis, Beverages, Desserts*) with instant search, *House Classics* filter, and dotted typographic leaders.
- **Architectural Editorial Layout**: Replaces generic card grids with exposed hairline rules, figure-captioned photography diptychs, a numbered Facilities & Spaces index, and a Founder's Monograph honouring Late Shri Jagannath B. Shetty (Est. 1951).
- **SEO & Structured Data**: Full Open Graph metadata and `Restaurant` + `LocalBusiness` JSON-LD schema.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
